# Bara'em Qassim - Project State Ledger & Technology Brief
**Project Authority**: Root AI engineering adhering to Najib's AI Engineering Guide & LMS Design System reference.

### 1. Project Technology Brief
- **Target Audience**: Kindergarten children (ages 4-6) in Qassim, Saudi Arabia, their parents, and kindergarten teachers/administrators.
- **Frontend Stack**: React 19 + TypeScript + Vite + Tailwind CSS v4 + Motion.
- **Visual Design System**: Learnly-inspired child-friendly EdTech design system:
  - Primary: Indigo & Royal Violet (`#6366F1`, `#4F46E5`, `#EEF2FF`)
  - Warm accents: Playful Orange (`#FB923C`), Golden Yellow (`#FBBF24`), Soft Emerald (`#10B981`), Sky Blue (`#0EA5E9`)
  - Typography: Tajawal (Arabic) + Plus Jakarta Sans (English)
  - Layout: RTL default with seamless LTR toggle; responsive for interactive touch displays, tablets, desktops, and mobile devices.
- **Audio & Haptics Engine**: Native Web Audio API audio synthesis (zero external audio asset latency) + Web Speech API for Arabic voice reading.
- **Data Architecture & Persistence**: Client-side reactive store backed by `localStorage` with rich realistic kindergarten seed data for Al-Qassim region (schools, classes, curriculum, activities, progress, rewards, assignments).
- **Safety & Privacy**: Child-safe environment, parent PIN-protected screen time limits, role-based boundaries, zero public child data, no external tracking.
